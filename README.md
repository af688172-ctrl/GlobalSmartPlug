# Global Smart Plug — Final Android UI

هذا هو التصميم التنفيذي الأول للتطبيق بناءً على التصميم الذي تم اعتماده:
- شاشة لوحة تحكم داكنة احترافية.
- المشترك الرئيسي.
- 4 مخارج.
- حالة Online.
- قراءة قدرة/جهد/تيار تجريبية.
- إضافة جهاز بالـMAC والـSerial.
- واجهة عربية.

مهم: قيم الطاقة الحالية تجريبية، وأزرار التشغيل تغير واجهة التطبيق فقط.
قبل التحكم الكهربائي الحقيقي يجب ربط Driver MTTL-W01 عبر الـAPI.
